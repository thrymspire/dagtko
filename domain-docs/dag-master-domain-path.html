Antenna Language // layer 5

federation · discovery · alignment · orchestration

Federated discovery and orchestration across independently projected Fragment substrates. Actionable only after Composition yields a measurable joined critical path.

Antenna is the highest named language. It represents federated discovery, alignment, and orchestration across independently projected Fragment substrates. Prerequisites are a stable Composition language and a measurable joined critical path. Cross-substrate Projection alignment and multi-domain orchestration remain future surfaces until those prerequisites hold.

Composition Language // layer 4

match · attach · validate · join · project · measure

Semantic joining of independently complete Fragments through matching Contracts. Produces a larger DAG whose structure is a Projection over existing Edges. No new mutation language.

Composition is the semantic joining of independently complete Fragments through matching published Contract identities. The result is a larger well-formed DAG whose current structure is represented by Projection over existing Edges. Composition must never require rewriting historical relations to make the joined graph true.

Ranked capability dimensions

  • R2 Acyclicity verification on the joined graph
  • R3 Derivation of joined Projection without mutation of source history
  • R4 Path-length analysis that yields a single critical-path measure
  • R5 Reproducible inspection of the joined structure

Bucket Language // layer 3

constraint · version · evaluate · permit · refuse

Versioned constraint domain evaluated against a proposed Edge before that Edge becomes historical fact. Refusal leaves history untouched; permit authorizes the atomic Event + Edge + Projection transition.

A Bucket is a versioned constraint domain against which a proposed Edge is evaluated before that Edge becomes historical fact. Evaluation uses the constraint state, the proposed Edge properties, and the current Projection of participating Nodes. Two outcomes exist: refuse (no new historical relation) or permit (Event + Edge + Projection update). Buckets are facts, not history-mutating processes.

ObjectVersioned constraint domain
StateApplicable constraint fact with historical attribution
RelationGoverns proposed Edge relative to current Projection
OperationName domain, version constraint, bind to proposed Edge, evaluate, refuse or permit
ConstraintEvaluation precedes emission; refusal produces no mutation; prior versions remain historical facts
EvidenceGiven Bucket state + proposed Edge + Projection, domain produces reproducible permit or refuse

Ranked capability dimensions

  • R1 Versioned constraint representation that itself remains historical fact
  • R2 Deterministic evaluation against proposed Edge and current Projection
  • R3 Atomic authorization boundary (permit produces the triple; refuse produces nothing)
  • R4 Decision traceability without alteration of prior Events
  • R5 Independent inspection of which constraint version governed a past decision

Contract Language // layer 2 · current focus

identity · ownership · boundary · crossing · projection shape

Declared interface owned and published by a Fragment. Specifies boundary Node types, crossing Edge types, and static Projection shape. Discoverable before any join.

A Contract is a declared interface owned and published by a Fragment. It specifies what may appear at the boundary, what relations may cross, and what Projection shape must remain compatible. It is a pre-existing discoverable fact, not a pair-wise agreement invented at join time. Projection-shape consistency is a static declaration; runtime verification only enforces that declaration. Mismatch becomes refused join, never corrective mutation.

ObjectPublished Contract identity
StateOwned, identifiable, discoverable, boundary-bound
RelationAssociates Fragment ownership with permitted Nodes, Edges, and Projection shape
OperationDeclare identity, bind boundary, publish, declare crossing rules, declare static shape, enforce, refuse
ConstraintOnly declared Nodes participate; only declared Edge types cross; shape is static; incompatible joins refused without history change
EvidenceAnother Fragment can discover the Contract and determine compatibility without first creating a join

Ranked capability dimensions

  • R1 Durable declaration of identity and ownership separate from runtime observation
  • R2 Typed boundary representation that distinguishes public Nodes from private Nodes
  • R3 Static constraint representation for Edge types and Projection shape
  • R4 Discoverability of the Contract as a domain fact before any composition attempt
  • R5 Compatibility evaluation that produces non-destructive refusal
  • R6 Independent inspection of the published declarations

Action sequence (domain order)

  • Declare Contract identity owned by the Fragment
  • Bind Contract to boundary Nodes (and Node types)
  • Publish Contract as discoverable domain fact
  • Declare permitted crossing Edge types and direction
  • Prevent internal Nodes from exposure
  • Statically declare required Projection shape
  • Treat runtime verification as enforcement only
  • Refuse incompatible composition without altering history
  • Declare Contract ready for discovery and matching

Fragment Language // layer 1

root · birth · scope · closure · dag · projection

Bounded, purposeful, directed acyclic set of Nodes and Edges with identifiable root, attributable Event history, and independent Projection. Primary unit of scale.

A Fragment is a bounded, purposeful, directed acyclic set of Nodes and Edges possessing an identifiable root and an independently meaningful Event history and Projection. It is the primary unit of scale. Birth occurs only through a typed creation Edge and corresponding Event. Internal Edges remain internal; only Contract-declared Edges may later cross. Critical-path length inside a Fragment is derived graph knowledge, never mutable business state.

ObjectFragment
StateClosed, purposeful DAG with root, attributable history, and current Projection
RelationRoot identity; membership boundary; Event-slice ownership
OperationDesignate root, emit creation Edge, bind Event scope, keep internal Edges private, derive Projection and critical path
ConstraintAcyclic; internally bounded; birth by creation Edge only; history attributable; Projection reconstructible
EvidenceFragment can be independently identified, traversed, projected, replayed, and validated as acyclic

Ranked capability dimensions

  • R1 Graph identity and root designation
  • R2 Directed relation construction with historical attribution
  • R3 Historical partitioning (Event slice attributable to the Fragment)
  • R4 Current-state derivation keyed by root
  • R5 Acyclicity verification and reproducible reconstruction

Substrate Language // layer 0

node · edge · event · projection

Four irreducible relations: Node identifies, Edge relates, Event records, Projection derives. Historical character is append-only. One complete Fragment unit must be jointly observable before concurrent birth is claimed.

The substrate has four irreducible domain commitments. Node answers what exists as an identifiable participant. Edge answers what directed relationship exists. Event answers what happened and in what order. Projection answers what is true now according to accumulated history. Higher languages consume Projection; direct Event interrogation is reserved for audit and reconstruction. The substrate is complete when one complete Fragment can be represented simultaneously as Node, Edge, Event, and Projection with historical character preserved.

ObjectFour relations (Node, Edge, Event, Projection)
StateJointly observable; append-only history; derived current truth
RelationNode participates in Edges; Edges originate Events; Events support Projection
OperationEstablish identity, establish directed contact, record occurrence, derive current truth, prove closed loop
ConstraintNo mutation of historical Events or Edges; Projection never becomes independent source of historical truth
EvidenceSeed unit jointly queryable; replay regenerates Projection; character locked for all higher languages

Ranked capability dimensions

  • R1 Durable identity representation and deterministic lookup
  • R2 Directed typed relation creation with historical origin
  • R3 Append-only occurrence recording with ordering and retrieval
  • R4 Deterministic derivation of current truth from Event history
  • R5 Joint observability of the four relations for one complete unit
  • R6 Reconstruction of Projection by replay alone

Physical-Work Grammar // every domain object

object → state → relation → operation → constraint → evidence → capability

Every actionable domain object is expressed in this sequence. The sequence is the bridge from ontology to physical work and to later tool-acquisition thinking. Capability remains ranked abstract dimensions; no tool is named here.

  • Domain Object — what entity or relation is being established
  • Required State — what must be true after the action
  • Precondition — what lower-layer fact must already exist
  • Domain Operation — what action is performed
  • Invariant — what must remain true during and after
  • Forbidden Transition — what must not happen
  • Evidence — observable fact that proves completion
  • Ranked Capability — ordered dimensions the environment must possess

Acquisition thinking works backwards: domain requirement → required capability dimensions → acquisition constraints → candidate capability → verification → action → domain evidence → workload completion. This prevents fitting the domain to whatever happens to be available.

Global Domain Laws // never restated per layer

  • Every business action becomes a typed Edge.
  • Projection is the sole current-truth surface.
  • Events remain append-only; historical Edges are never rewritten.
  • Fragment birth occurs through creation Edge + Event only.
  • Contracts are the sole legal Fragment crossing points.
  • Buckets gate Edge emission; they never rewrite history.
  • Composition is a Projection over existing Edges, never a new mutation language.
  • Any Projection can be rebuilt from its Event stream.
  • A higher language may compose lower facts; it may not invent historical truth that bypasses the substrate.
