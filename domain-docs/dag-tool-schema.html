Separation Rule // never contaminate

Domain actions never contain software names. Implementation bindings never redefine domain semantics. A successful process exit is never accepted as domain evidence. Derived state is never allowed to become historical truth.

  • Domain plane answers what must be possible.
  • Capability plane answers what must be provided.
  • Implementation plane answers by what physical means.
  • Verification proves the means satisfy the domain.
  • Evidence closes the loop back to the ontology.

L3 Bucket Tool Language // constraint gate

name · version · bind · evaluate · refuse · permit

Versioned constraint domain. Evaluate proposed Edge before it becomes historical fact. Refuse = no mutation. Permit = atomic Event + Edge + Projection.

Bucket evaluation is deterministic given the same constraint version, proposed Edge, and current Projection. Decision traces are themselves historical facts; they never alter prior Events.

Verification & Refusal Model // never conflate

Four distinct outcome classes must remain separate in every capability:

  • Execution failure — implementation could not perform the operation
  • Domain refusal — domain deliberately rejects the proposed transition (Bucket refuse, Contract mismatch)
  • Validation failure — operation completed but resulting state violates invariant
  • Evidence failure — state may exist but cannot be proven

Bucket refusal is never an execution failure. Contract mismatch is never an implementation crash. Cycle detection is never evidence failure. A process exit code is never domain evidence.

Reproducibility contracts

  • same Event sequence → same Projection
  • same graph → same acyclicity result and critical-path measure
  • same Bucket version + proposed Edge + Projection → same permit/refuse

Implementation Binding Plane // separate · replaceable

Bindings are not domain language. Existing major substrates supply identity, editing, analysis, and local execution surfaces. Additional free substrates fill ordered persistence, deterministic transform, graph traversal, visualization, and inspection. Any binding may be substituted if the capability contract is preserved.

Capability classes mapped (no software names in domain): durable structured persistence · ordered append · deterministic reduction · directed graph traversal · path analysis · declaration storage · constraint evaluation · discoverable fact index · visualization of derived structure · textual structural inspection · local process orchestration.

Substitution rule

primary_binding · alternative_binding · capability_equivalence · substitution_constraints. Changing a binding must not require changing Node, Edge, Event, Projection, Fragment, Contract, Bucket, Composition, or Antenna semantics.

Schema-Level Invariants // enforced globally

  • Every business action becomes a typed Edge.
  • Projection is the sole current-truth surface.
  • Events remain append-only; historical Edges are never rewritten.
  • Fragment birth occurs through creation Edge + Event only.
  • Contracts are the sole legal Fragment crossing points.
  • Buckets gate Edge emission and never rewrite history.
  • Composition is Projection over existing Edges; it creates no new mutation language.
  • Any Projection can be rebuilt from its Event stream.
  • Higher languages may compose lower facts; they may not invent historical truth that bypasses the substrate.

Architectural Test // mechanical answers

  • Substrate — one complete Fragment representable as Node+Edge+Event+Projection and reconstructible by Event replay?
  • Fragment — independently identified, bounded, acyclic, projected, replayable?
  • Contract — another Fragment can discover, inspect, and evaluate before attempting composition?
  • Bucket — proposed Edge evaluated deterministically, permitted atomically, or refused without mutation?
  • Composition — two valid Fragments match Contracts, verify compatibility, join, remain acyclic, produce Projection and measurable critical path without rewriting history?
  • Antenna — independently projected substrates discoverable, alignable, federatable, and orchestratable without a new historical-truth mechanism?

Any “no” identifies a missing capability that must be traced downward until the missing primitive is found.
